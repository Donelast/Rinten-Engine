# Controller models

The models in this folder are made from [WebXR Input Profiles](https://github.com/immersive-web/webxr-input-profiles) - `@webxr-input-profiles/assets` 1.0.20, `dist/profiles/<profile>/`. Each controller's moving parts were baked from the profile's own pressed poses into morphs (`trigger`, `grip`, `stick_press`, `stick_left`, `stick_right`, `stick_up`, `stick_down`, `button_a`, `button_b`) and exported as FBX; the pictures are the ones the originals carry. See `XrControllerModels` for how they are used.

Some portray registered trademarks of the device manufacturers so the controller looks like the one being held. The licence does not grant the use of those trademarks in derivative works (such as alternate controller skins), nor to endorse or promote a product.
